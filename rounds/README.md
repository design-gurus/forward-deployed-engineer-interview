# Rounds

Each page explains one round type: what the interviewer measures, how the time is usually divided, and what a strong answer contains. No company uses every round, so start with [the interview loop](interview-loop.md) to see which ones apply to you.

| Round | Tests | Most associated with |
|---|---|---|
| [The interview loop](interview-loop.md) | The whole process, stage by stage | Every company |
| [Decomposition](decomposition.md) | Turning a vague need into a buildable plan | [Palantir](../companies/palantir.md) |
| [Discovery and scoping](discovery-and-scoping.md) | Questions, the named user, and the first version | Every customer round |
| [The learning round](learning-round.md) | Using code and documentation never seen before | [Palantir](../companies/palantir.md) |
| [The re-engineering round](re-engineering-round.md) | Debugging unfamiliar code | [Palantir](../companies/palantir.md) |
| [Practical coding](practical-coding.md) | Data handling, APIs, SQL, and staged requirements | Every company |
| [Applied AI system design](applied-ai-system-design.md) | A customer system that contains a model | [OpenAI](../companies/openai.md), [Anthropic](../companies/anthropic.md), [Google](../companies/google.md) |
| [The take-home project](take-home-project.md) | Build quality and customer framing | [OpenAI](../companies/openai.md), [Cognition](../companies/cognition.md) |
| [The project deep dive](project-deep-dive.md) | Ownership of a past system | [OpenAI](../companies/openai.md), [Anthropic](../companies/anthropic.md), [Cognition](../companies/cognition.md) |
| [Behavioral questions for customer work](behavioral-for-customer-work.md) | Trust, judgment, and motivation | Every company |
